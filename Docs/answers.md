I don't necessarily believe they should be the same, more so "roughly". But of course there might be other answers, like that some might be less suseptible to coldness. G and C bonds have an additional hydrogen bond that stabilizes the genome in colder environments, though this idea has been challenged in eukaryotes. 

There are a lot of different examples of genome evolution that may cause AT/GC mutation bias, like that GC-richness differs  between species of different host due to altered selective pressures. There might have been gene duplications in some linages, whilst others might have aquired GC repetitive elements (transposable insertions).
